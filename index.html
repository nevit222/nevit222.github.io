About Us

Tentang Ans Bee App

Ans Bee App adalah studio kecil yang fokus bikin aplikasi mobile yang simpel dan berguna. Kami berbasis di Manado dan lebih memilih membuat produk yang benar-benar dipakai, bukan sekadar terlihat keren.

Ans Bee App is a mobile application development studio based in Manado, North Sulawesi, Indonesia — focused on building simple, functional apps that deliver real value to everyday users.

Kami memperhatikan hal-hal kecil — mulai dari tampilan, performa, sampai privasi pengguna. Tujuannya sederhana: aplikasi terasa ringan dan nyaman dipakai setiap hari.

Every app we release is built with careful attention to detail, user privacy, and a smooth experience — from interface design to technical performance.

Ke depan, kami akan terus merilis aplikasi yang fokus ke kebutuhan sehari-hari — ringan, cepat, dan benar-benar kepakai.

Going forward, Ans Bee App plans to release more apps focused on everyday utility — lightweight, reliable, and genuinely useful.

Semua data keuangan Anda disimpan sepenuhnya di perangkat Anda sendiri menggunakan database lokal terenkripsi. Kami tidak memiliki server yang menyimpan data pribadi Anda — tidak ada akun, tidak ada sinkronisasi cloud (kecuali backup yang Anda lakukan sendiri).

All your financial data is stored locally on your device using an encrypted local database. We have no server storing your personal data — no accounts, no cloud sync (unless you manually back up).

Fitur backup tersedia untuk pengguna Premium. Ekspor data ke file .nectarbackup terenkripsi AES dengan password pilihan Anda, simpan di lokasi mana saja, dan restore kapan saja dari dalam aplikasi.

Backup is available for Premium users. Export your data to an AES-encrypted .nectarbackup file, save it anywhere, and restore it anytime from within the app.

Fitur dasar seperti transaksi, budget, laporan, tabungan, dan utang-piutang tersedia gratis. Premium mencakup: backup & restore terenkripsi, foto bukti transaksi, ikon kustom, dan ekspor PDF penuh tanpa iklan.

Core features (transactions, budget, reports, savings, debts) are free. Premium unlocks: encrypted backup/restore, receipt photos, custom icons, and full PDF export without ads.
