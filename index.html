Kenapa Nectar Wallet?

Ringkas, privat, dan enak dipakai.

Nectar Wallet dibuat untuk kebiasaan sehari-hari: buka, catat, selesai. Fitur utama tetap bisa dipakai tanpa login dan internet.

🔒

Privasi Lebih Tenang

Data disimpan lokal secara default. Cloud terenkripsi hanya aktif setelah kamu memilih dan menyetujuinya.

✈️

Bisa Dipakai Offline

Fitur utama tetap jalan tanpa internet. Koneksi hanya dipakai untuk iklan versi gratis dan validasi Premium.

💸

Fitur Utama Gratis

Transaksi, budget, laporan, tabungan, dan utang-piutang bisa dipakai gratis. Premium tersedia untuk kebutuhan tambahan.

🛠️

Terus Dikembangkan

Bug diperbaiki, masukan pengguna dibaca, dan aplikasi rutin diperbarui.

Bantuan & FAQ

Ada pertanyaan?

Beberapa jawaban cepat soal data, backup, Premium, dan cara menghubungi kami.

Data keuangan disimpan lokal secara default. Jika kamu mengaktifkan Sinkronisasi Cloud Premium Plus, data finansial teks dienkripsi di perangkat sebelum dikirim; foto struk dan gambar kustom tetap lokal.

Backup tersedia untuk pengguna Premium. Kamu bisa mengekspor data ke file .nectarbackup terenkripsi AES dengan password pilihanmu, lalu restore lagi dari aplikasi kapan saja.

Fitur utama seperti transaksi, budget, laporan, tabungan, dan utang-piutang tersedia gratis. Premium menambahkan backup dan restore terenkripsi, foto bukti transaksi, ikon kustom, dan ekspor PDF penuh tanpa iklan.
